# Icon Files

The application needs icon files in PNG format for Electron builds.

To generate icons from the SVG:
1. Use an online converter or tool like ImageMagick
2. Generate at these sizes: 16x16, 32x32, 64x64, 128x128, 256x256, 512x512
3. Name the main icon as `icon.png`

For now, the SVG icon will be used during development.
